# Total on Windows

Total works the same on Windows as on a Mac: the same screens, the same books, the same backups. A few things look or behave a little differently, and this page lists them.

## Keys

On Windows you press **Ctrl** where a Mac uses its Command key, and **Alt** where a Mac uses Option. Total shows the Windows keys on screen: **Ctrl+K** to search, **Ctrl+Enter** to save, **Ctrl+J** to ask Total. See [Keyboard shortcuts](total://help/keyboard-shortcuts).

## Where your books are

Your books are in the **total** folder inside your **Documents** folder (Documents\total). If Windows backs up your Documents folder to OneDrive, Total says so when it starts: a file that is being written while it is copied to the cloud can be damaged. Open the books on one computer at a time, and keep your own backups too — see [Backups](total://help/backups).

If your books are in OneDrive, Total shows a warning in Settings. To move them to a folder OneDrive does not sync (for example a new folder on drive C or D), open [Settings → Backups](total://screen/simple-backups) and choose **Move to another folder…** under **Where Total keeps your books**. Pick an empty folder. Total copies everything, checks the copy and restarts. The old folder is kept as it was, with a note saying where your books went; delete it yourself once you have checked your books in the new place.

## Installing and updates

Total is installed for you only, so it does not ask for an administrator password. Total is not yet signed with a publisher certificate, so the first time you run the installer Windows may show **Windows protected your PC**. Choose **More info**, then **Run anyway**.

New versions download by themselves and are put in when you close Total. Your books are never touched by an update, and removing Total from Windows keeps them.

## Files and names

- A PDF opens in your usual PDF app, and **Show in folder** opens File Explorer.
- Files made on Windows — a Tally export saved as **Unicode**, a bank statement saved from Excel — are read just like files from a Mac.
- Windows keeps a few names for itself (CON, PRN, AUX, NUL, COM1 and the like). A business with one of these names gets "-company" added to its folder name; the business name itself does not change.

## Saved passwords and keys

The key for the [AI helper](total://screen/simple-ai) and your e-invoice login are kept with Windows' own protection for your Windows account. On a new computer, type them in again — they are never put in a backup.
