# Keyboard shortcuts

You can do everything with the mouse, but these keys save time.

## Everywhere

- **⌘K** — Search: find a customer, product, bill or task and open it.
- **⌘J** — Ask Total a question.
- **?** or **⌘/** — help for the screen you are on.
- **Esc** — close a box, or go back.

## In a form (bill, purchase, money in, money out)

- **⌘↵** — Save.
- **⌘N** — start a new one.
- **Tab** — the next box; **Shift-Tab** — the box before.
- In a list of choices, **↓** and **↑** move and **Enter** picks the highlighted one. Enter never adds something new: to add a new name, press **↓** past the last match to **Create …**, then Enter.

## In a list

- **↓** and **↑** move between rows; **Enter** opens the row.

On Windows, Total shows these keys with **Ctrl** (the Mac's Command key) and **Alt** (the Mac's Option key) — see [Total on Windows](total://help/windows).
