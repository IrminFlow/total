# Windows par Total

Windows par Total waise hi chalta hai jaise Mac par: wahi screens, wahi hisaab, wahi backups. Kuch cheezein thodi alag dikhti ya chalti hain — woh is page par hain.

## Keys

Windows par aap wahan **Ctrl** dabate hain jahan Mac par Command key hoti hai, aur wahan **Alt** jahan Mac par Option. Total screen par Windows ki keys hi dikhata hai: search ke liye **Ctrl+K**, save ke liye **Ctrl+Enter**, Total se poochne ke liye **Ctrl+J**. Dekhein [Keyboard shortcuts](total://help/keyboard-shortcuts).

## Aapka hisaab kahan hai

Aapka hisaab aapke **Documents** folder ke andar **total** folder mein hai (Documents\total). Agar Windows aapka Documents folder OneDrive par backup karta hai, to Total shuru hote waqt yeh batata hai: jo file likhi ja rahi ho aur usi waqt cloud par copy ho rahi ho, woh kharab ho sakti hai. Hisaab ek waqt mein ek hi computer par kholein, aur apne backups bhi rakhein — dekhein [Backup](total://help/backups).

## Install aur updates

Total sirf aapke liye install hota hai, isliye yeh administrator password nahi maangta. Total par abhi publisher ka certificate (signature) nahi hai, isliye pehli baar installer chalane par Windows **Windows protected your PC** dikha sakta hai. **More info** chunein, phir **Run anyway**.

Naye version apne-aap download hote hain aur Total band karne par lag jaate hain. Update aapke hisaab ko kabhi nahi chhoota, aur Windows se Total hatane par bhi hisaab bana rehta hai.

## Files aur naam

- PDF aapke usual PDF app mein khulti hai, aur **Show in folder** File Explorer kholta hai.
- Windows par bani files — **Unicode** mein save kiya gaya Tally export, Excel se save kiya gaya bank statement — waise hi padhi jaati hain jaise Mac ki files.
- Windows kuch naam apne liye rakhta hai (CON, PRN, AUX, NUL, COM1 jaise). Inmein se kisi naam wale business ke folder ke naam mein "-company" jud jaata hai; business ka naam nahi badalta.

## Save kiye gaye password aur key

[AI helper](total://screen/simple-ai) ki key aur aapka e-invoice login Windows ki apni suraksha ke saath aapke Windows account ke liye rakhe jaate hain. Naye computer par inhein phir se likhein — yeh kabhi backup mein nahi jaate.
