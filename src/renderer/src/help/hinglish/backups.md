# Backups

Aapka hisaab sirf isi computer par, aapke Documents folder mein rehta hai. Backup ek copy hai, jis par aap laut sakte hain — agar computer kharab ho jaaye ya kho jaaye, ya kuch galat likh diya gaya ho.

## Abhi backup lein

Left side mein sabse neeche **Abhi backup lein** dabayein. Ismein ek second lagta hai. Har kaam ke din ke ant mein aisa karein.

Agar aapka aakhri backup ek hafte se zyada purana hai, to Home aapko yaad dilata hai.

## Ek copy kahin aur rakhein

Usi computer par rakha backup tab kaam nahi aata jab computer hi kho jaaye. Beech-beech mein apne backups kisi pen drive par, ya kisi bharosemand cloud folder mein copy karein. [Settings → Backups](total://screen/settings?tab=backups) batata hai ki woh kahan rakhe hain.

## Backup wapas laana

Business kholein, [Settings → Backups](total://screen/settings?tab=backups) par jaayein, list mein backup chunein aur **Restore…** dabayein. Hisaab waisa hi ho jaata hai jaisa woh backup banate samay tha.

Passphrase ke saath save kiya gaya backup (Settings → Backups mein **Export encrypted…**) doosre computer par bhi khola ja sakta hai: jis screen par aap business chunte hain, wahan **Import encrypted backup…** chunein aur passphrase likhein.

## Total aapka hisaab kahan rakhta hai

[Settings → Backups](total://screen/settings?tab=backups) woh folder dikhata hai jismein aapka hisaab aur backups rehte hain. Agar woh OneDrive ya kisi aur cloud-sync folder ke andar hai, to Total chetavni deta hai, kyunki sync karne wala program hisaab mein dakhal de sakta hai.

Badalne ke liye **Doosre folder mein le jaayein…** dabayein aur koi khaali folder chunein. Total sab kuch copy karta hai, copy jaanchta hai aur dobara chalu hota hai. Purana folder mitaya nahi jaata, par us par wapas na jaayein — uska hisaab purana hai. Jahan business mein sign-in hain, wahan sirf maalik ise le ja sakte hain.
